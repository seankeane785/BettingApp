# Codex instructions

- Inspect Git status, current code and documentation before material changes.
- Preserve existing work; never make destructive, unrelated or broad cleanup changes.
- Use React, TypeScript and Vite for the local-first browser application.
- Version 1 has no backend and no automated data collection, APIs or scraping.
- Do not introduce odds-related content, including prices, payouts, implied probability, expected value, value betting or bookmaker links.
- Support team-level markets only; exclude player-specific markets.
- Keep analysis deterministic and permit “No qualifying builder today”.
- After material changes, update relevant documentation and tests plus `docs/BUILD_LOG.md` and `docs/KNOWN_ISSUES.md`.
